Seven Clean Bills That Were Wrong the night's actual theme
Every one of these reported no problem while a problem was running. None threw an error. The failure mode is not a tool that breaks — it is a tool that answers confidently about something it never actually measured.
What to check next time Before trusting a watcher's silence, make it report what it matched, not just what it flagged. A detector that scans 2,526 rows and finds nothing should say "scanned 2,526, matched 0" — the row count is the proof the query was alive. Four of the seven below would have been caught on sight by that one line.
